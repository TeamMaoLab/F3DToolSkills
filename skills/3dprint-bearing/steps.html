3D 打印轴承 · 构建步骤

孔内成型 · gen_bearing_full.py · 点击大步骤展开小步骤 · 验收点标绿
S0输入与配方派生
  1. 读设计选择集里的圆柱孔面（无则自愈：删旧组件反推孔签名）
  2. 反读基准系：轴向 u / 孔口 A0 / 半径 R_h / 深度 D_h（椭圆环缘定向，面积法在斜孔下不准）
  3. 文档属性 F3DToolSkills 组参数覆盖（N_BALLS/DBALL/CLR/RFILLET）
  4. 配方派生：R_track=R_h−δ−壁厚、R1–R5、窝 rg=球/2+clr、球数 N 公式（θ口/θ窝/θ球 取 max）
验收：孔深 ≥ 球径+2clr+1.1；两端环缘为正圆（斜孔拒绝）
S1过轴平面
  1. 按孔轴 u 建过轴基准面（构造平面，按名复用）
验收：平面法向 ⊥ u
S2闭环截面草图
  1. 截面三闭环：内盘剖面 / 中环剖面（球道凹口）/ 外环剖面
  2. r=0 构造线兼旋转轴；全构造线打底，尺寸回溯到 S0 参数
  3. 世界坐标落笔一律 modelToSketchSpace()
验收：profile 数 in=1、ring=1、out=1
S3旋转三体
  1. 三剖面分别 revolve 成内盘 / 中环 / 外环毛坯（3 参 createInput + .operation）
验收：体积对账（理论公式 vs 实测）；分类命名正确
S4球窝切割
  1. 球刀 tempBrep 球体（窝半径 rg）
  2. 刀体圆周阵列 ×N（combine 不可阵列——先阵列刀再一次性 Cut）
  3. 对中环一次 Cut 出全部球窝
验收：窝面型 = Torus 真弧（折线=废品）；窝数 = N
S5装球口（V 形凸雕）
  1. 切平面三点式挂草图参考点（防圆角断链）
  2. 楔形草图 → 凸雕 V 口（开口朝 +Y 侧）
验收：凹陷方向（质心径向 < R3）；连续区面法向校验
S6标准球 + 圆周阵列
  1. tempBrep 标准球（球心 z=孔深/2，骑 R_track 圆）
  2. 圆周阵列 ×N（ObjectCollection 入参）
验收：球心共面 z=D_h/2；球数 = N
S7口棱圆角
  1. 边集筛选：凹陷面 ∩ 球窝面交界（每球位 2 条，不是 V 口侧棱）
  2. 一个特征全倒（阵列复制不了圆角——先阵列后圆角）
验收：圆角面积 = 1.192×2/球位
S8宿主融合
  1. 外环 JOIN 进宿主；融合特征签名含宿主名（防同径多孔互清杀）
验收：宿主上 Torus 面 ×1
S9整理与验收
  1. 球自然序重命名（球01…球NN，无 "(1)" 后缀）
  2. 脚手架收起：草图 isVisible=False、构造面灭灯
  3. 选择集：no3dprint（全部球，导出打印时一键隐藏；root 视图 occ 收集）
  4. verify 汇总 + 生成 HTML 报告（桌面 + /report）
验收：总结论 PASS ✓ 才算交付；幂等重跑两轮一致
