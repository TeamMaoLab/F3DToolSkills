# 自定义球轴承球径缩放推演（⌀3 → ⌀2.5 / ⌀2.381，2026-08-18）

> 需求：⌀3 球成本高，研究换 **⌀2.5** 或 **⌀2.381（=3/32″，英制标准钢球，散装极便宜）**。
> 3D 打印做这种轴承效果可以接受。本文从截面草图一步步推演哪些量随球缩放、哪些不缩，
> 结论已落地：设计器加「轴承球径」预设、`gen_bearing_full.py` 参数化 `DBALL`。

## 一、结论速览

0. **全局统一球规格（2026-08-18 用户定则）**：整个系统永远只用一种球，**选项就两个：⌀2.381(3/32″)
   / ⌀2.5（默认 2.381）**——偏心孔轴承球与层间支撑球共用。设计器两下拉已并为一个（`ballD`），
   方案 JSON 只留 `ballD+brgClr`，`gen_bearing_full.py` `DBALL` 同源；⌀3 从系统选项中移除
   （保留在本文档作为实验室基准与推演锚点）。

1. **配方里唯一随球走的是窝半径**：`rg = dBall/2 + clr`（clr=0.05 打印间隙，绝对值）。
   δ=0.8、中环厚 1.0、外环壁厚 2.0、间隙 0.3、装球口宽 5.0——**全是打印绝对值或孔驱动，不随球缩放**。
2. **同孔径下换小球，球数 N 不变**：N = ⌊360°/max(θ口,θ窝,θ球)⌋，而 max 几乎恒为 θ口
   （装球口占角），θ口 只与孔深/口宽有关，与球径无关。锚点回归：⌀12→N4 / ⌀16→N6 / ⌀20→N8，
   三种球径结果完全一致。
3. **小球的真实收益**：球便宜一个量级、最小孔径下探（⌀10.5→⌀9.9）、端面窝上缘更厚
   （0.95→1.26，打印不易掉边）、相对啮合更深（δ/(d/2)：0.53→0.67，球更不容易掉）。
4. **想把 N 加上去，杠杆是装球口不是球**：口宽 slotW = D_h·tan(wEdge/2)，把 V 口从 90° 收窄到
   70°（slotW 5.0→3.5）⌀16 孔就能 N=8——且入口余量 slotW−d 对 ⌀3 只剩 0.5（紧），
   对 ⌀2.5/⌀2.38 有 1.0/1.12（舒服）。**窄口方案与小球是绝配**（见 §五）。
5. **孔深 D_h 是同一杠杆的另一头，而且小球让孔可以更浅**：slotW = D_h（wEdge=90° 时），
   孔从 5 浅到 4 → 口窄到 4 → θ口 55.5°→47.4° → **⌀16 孔 N 6→7，还白赚 1mm 厚度**。
   孔深下限由窝上缘决定：D_h ≥ d+1.2（⌀3→4.2、⌀2.5→3.7、⌀2.381→3.58）
   ——**⌀2.38 用 4mm 深，⌀3 不行**（见 §六）。

## 二、从截面草图一步步推

截面 = 过孔轴平面。配方的一切都挂在「球心圆」上（⌀d 的圆，圆心在半径 R_track、高度 D_h/2）。

**第 1 步 · 球心圆**：球心位置由孔反读锚定：R_track = R_h − δ − t_wall，zB = D_h/2。
到这里球径还没出场——球心圆的**位置**与球大小无关，变的只是圆的**粗细**。

**第 2 步 · 窝（唯一球驱动量）**：球刀半径 = 球半径 + 间隙：
`rg = dBall/2 + clr`。clr 是**可选参数（默认 0.2）**：间隙补的是**打印机**公差，和球大小无关——
光固化 0.05（实验室原版）/ FDM 0.2（0.1 对打印偏挤）。⌀2.5+clr0.2→rg 1.45；⌀2.381→1.39。

**第 3 步 · 三环嵌套（打印绝对值）**：中环夹球心圆 ±t_ring/2；内盘/外环边界离球心圆 δ；
三体间径向间隙 = δ − t_ring/2 = 0.3。这三个量（δ=0.8、t_ring=1.0、t_wall=2.0）由
**打印机最小壁厚/最小间隙**决定，不由球决定——球缩了壁不缩，结构强度不降。
副作用反而是好的：球越小米径越细，同样的 δ 啮合越深（δ/(d/2)：0.53→0.67），球更不容易脱出。

**第 4 步 · 装球口（孔驱动，与球无关）**：V 楔顶点在球心等高处、底在孔口端面，所以
`slotW = 2·(D_h − zB)·tan(wEdge/2) = D_h·tan(wEdge/2)`（zB=D_h/2）。
D_h=5、wEdge=90° → slotW≡5.0，**不管球多大**。小球进 5.0 的口只是更宽裕。

**第 5 步 · 球数公式（θ口主导）**：
```
N = ⌊360° / max(θ口, θ窝, θ球)⌋
θ口 = 2·atan((slotW/2+0.5)/R3)          ← 只与 slotW（=孔深驱动）、R3 有关，与球无关
θ窝 = 2·asin(√(rg²−0.3²)/R2)            ← 随 rg 缩小而缩小
θ球 = 2·asin((dBall+0.3)/(2·R_track))   ← 随球缩小而缩小
```
球缩小 → θ窝/θ球 缩小 → max 更是 θ口说了算 → N 不变。数值验证见 §四。

## 三、参数分类总表

| 类别 | 参数 | 取值 | 为什么 |
|---|---|---|---|
| **球驱动** | 窝半径 rg | d/2+clr | 球贴窝跑，间隙补打印机公差 |
| **打印绝对值** | 窝间隙 clr | **可选，默认 0.2**（0.05 光固化 / 0.1 / 0.15 / 0.2 FDM） | 打印机公差；影响 rg/最小孔(+2clr)/孔深下限(+2clr)/θ窝，不影响 N（θ口主导） |
| | 端面距 δ | 0.8 | 球道啮合深度，最小壁厚驱动 |
| | 中环厚 t_ring | 1.0 | 最小壁厚 |
| | 外环壁厚 t_wall | 2.0 | 强度 |
| | 三体径向间隙 | 0.3 = δ−t_ring/2 | 最小间隙 |
| | V 口角 wEdge | 90° | 装球口形状（想加 N 才动它，见 §五） |
| | 圆角 rFillet | 1.0 | 口沿抗崩 |
| **孔驱动** | 孔深 D_h | 5（应用锁死） | 轴承区厚度 |
| | 口宽 slotW | D_h·tan(wEdge/2) | 楔几何推导值，不是自由参数 |
| | R_track | R_h−δ−t_wall | 同心放法 |
| | zB | D_h/2 | 球心轴向位置 |

## 五、想加 N：收窄装球口（wEdge），与小球绝配

N 的瓶颈是 θ口，唯一不动孔径的杠杆是 slotW = D_h·tan(wEdge/2)。对 ⌀16 孔：

| wEdge | slotW | θ口 | N（三球径同） | 入口余量 slotW−d：⌀3 / ⌀2.5 / ⌀2.381 |
|---|---|---|---|---|
| 90°（现行） | 5.00 | 55.5° | 6 | 2.00 / 2.50 / 2.62 |
| 80° | 4.20 | 49.0° | 7 | 1.20 / 1.70 / 1.81 |
| **70°** | **3.50** | **43.1°** | **8** | 0.50（紧）/ 1.00 / 1.12 |
| 60° | 2.89 | 37.7° | 9 | 装不进 / 0.39（紧）/ 0.51 |

- wEdge=70° 让 ⌀16 孔 N=8（球数 +33%，承载/平稳性都上去）；
  ⌀3 球入口只剩 0.5 余量勉强能装，**⌀2.5/⌀2.38 余量 1.0+，装球无压力** —— 这才是换小球真正的结构性理由。
- 窄口代价：V 楔更深地切进中环端面附近，打印悬垂稍差；建议树脂打印。
- 此项**尚未落地**到脚本/设计器（现行 wEdge 仍 90°），要做的话在 `gen_bearing_full.py` 的
  slotW 计算和楔草图里把 45° 壁角换成参数。

## 六、孔深杠杆：⌀2.38 → 4mm 深（不用 5mm）

孔深不是被动约束，是主动杠杆——**因为它直接决定装球口宽**：

```
zB = D_h/2（球心跟孔深中点）     窝上缘余量 L = D_h/2 − rg
slotW = 2·(D_h−zB)·tan(wEdge/2) = D_h·tan45° = D_h   → 孔浅口窄 → θ口小 → N 增加
```

**孔深下限两档**：硬线 = 窝不穿端面 D_h > 2rg = d+0.1；打印实用线 = 窝上缘 ≥0.55 ⇔ **D_h ≥ d+1.2**。

| 球径 | 硬线 | 打印实用线 | 4mm 深可行？ |
|---|---|---|---|
| ⌀3 | >3.10 | ≥4.20 | ✗（窝上缘仅 0.45，易掉边） |
| ⌀2.5 | >2.60 | ≥3.70 | ✓（0.70） |
| **⌀2.381** | >2.48 | ≥3.58 | **✓（0.76）** |

⌀16 偏心孔、D_h 5→4 的完整对比（wEdge=90°）：

| | 深 5 | 深 4 |
|---|---|---|
| slotW / θ口 | 5.0 / 55.5° | 4.0 / 47.4° |
| N（⌀2.381） | 6 | **7** |
| 窝上缘（⌀2.381） | 1.26 | 0.76 |
| 入口余量 slotW−d | 2.62 | 1.62 |

D_h=4 + ⌀2.381 各孔径 N：⌀12→5，⌀16→7，⌀20→10（对比 D_h=5 的 4/6/8，全线 +1~+2）。

**摆线盘应用**：discT=4（=孔深）→ 三片叠高 16.2→13.2mm，偏心孔 ⌀16×4 装 7 球轴承。
支撑球 Z 栈自动跟随（球心 z=4.3/8.9）。注意叠高变矮后支撑球咬合量不变（球径−gap）/2 与 D_h 无关。

理论地板：⌀2.381 最浅 3.58（打印线）；再往下要动 clr 或接受薄窝上缘，不建议。

**推荐配对（草图页已做自动吸附；窝上缘括号为 clr=0.05 / clr=0.2）**：⌀3→D_h 5；
⌀2.5→D_h 4（窝上缘 0.70 / 0.55，N@⌀16=7）；⌀2.381→D_h 4（0.76 / 0.61，N@⌀16=7）。
换球径时孔深自动吸到推荐值，仍可手动覆盖。clr=0.2 时孔深下限 = d+2clr+1.1（⌀3→4.5、
⌀2.5→4.0、⌀2.381→3.88），⌀3@深4 在 clr=0.2 下窝上缘仅 0.30，明确不可用。

  顶部 `CLR` 常量三处同步；换 clr 只改 rg 一条链（最小孔 +2clr、孔深下限 +2clr、θ窝 微增），N 不变。
- 球心 zB=D_h/2、窝弧、切线引出 45° 全不变——三体装配关系与 ⌀3 完全同构。
