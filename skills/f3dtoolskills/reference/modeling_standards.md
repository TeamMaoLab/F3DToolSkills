# 实体建模通用规范（任何建模任务都适用，非应用专属）

来自 TeamMaoLab 实战沉淀。违规的典型症状：模型"能看但没法维护"——浏览器树一堆
Body1/Body2/草图1/草图2，改一个参数全崩。

## 1. 命名体系（浏览器树即文档）

- **实体**：中文语义名，`内盘` / `中环` / `外环` / `球01…球NN`（自然序两位数字，**不用**
  Fusion 自动加的 `(1)` 后缀）。创建后立即 `body.name = ...`。
- **特征**：中文动词短语，说清"做了什么"——`内盘旋转` / `球窝切割×N` / `装球口` /
  `口棱圆角` / `圆周阵列`。分步大任务用自进度名（`摆片1-胶囊板` → `摆片1-齿形孔` →
  …，看时间线即知进度，幂等重跑跳过已完成步）。
- **草图**：`{用途}` 或 `{用途}-{平面}`，如 `球窝截面` / `摆片2-Y平面18`。
- **构造平面**：按零件命名（`摆片k-Z基准`），**只删自己的**——全清会孤儿化别人草图的参考。
- **组件**（装配文档）：签名带关键维度+宿主，`轴承-全-实体85-⌀38`；只写孔径会在同径
  多孔时互相清杀。

## 2. 草图纪律（程序化 ≠ 不可回溯）

- 草图**全用构造线**打底：每个尺寸能回溯到公式/常量，用户点开看得懂怎么来的。
- 参数三层：**外参**（用户输入）/ **配方**（设计定则锁死）/ **派生**（公式算出）——
  派生量在脚本里显式重算并与来源交叉校验，漂移即中止。
- 复杂轮廓与构造线**分草图隔离**——直接建模文档里构造线会切碎 profile 区域。
- 落笔世界坐标→草图用官方 `sketch.modelToSketchSpace()`，别手写逆映射（符号错必翻面）。

## 3. 构建过程（分步 + 对账）

- **一步一特征**，每步建完立刻对账：体积/面积/Z 区间/关键点位置 vs 理论公式
  （回转体用 Pappus 定理交叉验证切量）。对不上当场停，别继续往上盖。
- **幂等可重入**：每步开头清理同重名特征/草图/实体再重建；删组件先删特征再删 body、
  倒序多趟。重跑第二遍结果必须与第一遍逐位一致。
- 千点级样条别一次上（卡死 Fusion），加密采样小步试。

## 4. 验收（交付门槛）

1. 读回几何证据（不是 API 返回值）：bbox、体积、Torus 圆心、孔数、面型分布；
2. 幂等重跑两轮 PASS；
3. 改一个参数（篡改测试）重跑，结果按预期变化——证明参数真的接通了。

## 5. 收尾（脚手架清理）

- 全部草图 `isVisible=False` 收起；构造面灭灯；浏览器树只留成品实体。
- 批量交付物建选择集/球组子组件分组（参照 3dprint-bearing 的命名与分组规范）。

## 6. 演示/临时模型也要守 1、3、5

"只是画个看看"不是糊弄的理由：命名、对账、收尾三样一样不能少——演示模型往往
活到第二周就变成了正式模型。
