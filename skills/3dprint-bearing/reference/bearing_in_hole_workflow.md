# 自定义球轴承「孔内成型」固定流程（广义孔版，2026-08-17）

> 需求：在已有实体间快速掏一个 3mm 自定义球轴承。手动流程固定且重复多次，
> 本次完成全流程逆向 + 广义化验证：**输入 = 任意位置/姿态的 ⌀25.6×5mm 圆柱孔，
> 输出 = 三体 + 球的完整轴承**，已在倾斜孔 Demo 上跑通（反读基准零误差）。

## 一、参数表（从「轴承实验室 v2」逆向提取，mm/deg）

**外参（锚：来自输入孔 + 方位选择）**

| 参数 | 默认 | 含义 |
|---|---|---|
| hole_axis / A0 | 选孔面反读 | 孔轴（底→口）与孔底圆心，任意姿态 |
| R_h | 12.8 | 孔半径 = 外环外径（轴套贴孔壁） |
| D_h | 5（需求硬约束） | 孔深 = 轴承区轴向厚度（下限随球径 d+1.2：⌀2.381 最浅 3.58 可用 4mm 深孔，⌀3 需 ≥4.2；slotW=D_h·tan(wEdge/2) 孔浅口窄 N 反增，见 bearing_ball_sizes.md） |
| α0 | 任意 | 装球口方位角（= 圆周阵列起点） |

**配方参数（轴承本体，可全部挂用户表达式）**

> 球心是一等参数：草图1 的 ⌀3 构造圆 = 整个配方的原点（窝、切线、楔顶点、球刀、标准球全挂在它上面）。
> 依赖方向是「球驱动」：先定球心位置，再往外长身体；孔只是锚 + 兼容性校验。

| 参数 | 默认 | 含义 / 依赖 |
|---|---|---|
| R_track | 10 | **球心径向位置**（球道分布圆半径，lab d1=10 那个基准的真正角色） |
| zBall | D_h/2（lab 2.5） | **球心轴向位置**（距孔底高度；窝/球道/V 楔顶点全部跟随） |
| dBall | 3 | 球径（标准系列 2/2.38/2.5/2.8/3/4；换球径的缩放推演见 `docs/bearing_ball_sizes.md`——只有 rg=d/2+0.05 随球走，其余参数不缩） |
| clr | 0.05 | 窝间隙 → 窝半径 rg = dBall/2 + clr（lab d3=⌀3.1） |
| halfAng | 45° | 窝开口半角（窝 = 2×45° 弧 + 切线引出；lab d4） |
| δ | 0.8 | 端面距球心：内盘外径/外环内径 = R_track∓δ（lab d5） |
| t_ring | 1 | 中环径向厚：R_track±t_ring/2（lab 矩形 d8） |
| t_wall | 2 | 外环壁厚：外环外径 = R_track+δ+t_wall = R_h（lab d6） |
| wEdge | 90° | 装球口 V 楔角（lab d11），顶点自动=球心等高 |
| dEmboss | −t_ring | 凸雕深度（打穿中环壁；lab −1.00） |
| rFillet | 1 | 圆角边=**凹陷面∩球窝面**的交界（壁厚中段、球心上方、长约1.0~1.4、每球位2条），非相切链；面片≈1.19mm²×2/位 |
| N | 8 | 球数（圆周阵列 quantity，挂 ModelParameter） |

**派生量（不给参数，公式算）**

| 量 | 公式 | lab 值 |
|---|---|---|
| 内盘外径 / 外环内径 | R_track ∓ δ | 9.2 / 10.8 |
| 中环径向范围 | R_track ± t_ring/2 | 9.5~10.5 |
| 外环外径 | = R_h（轴套贴孔壁） | 12.8 |
| 窝深 | rg − δ | 0.75 |
| 中环↔内盘/外环径向间隙 | δ − t_ring/2 | 0.3 |
| 窝口半宽（端面处切线口） | √(rg²−δ²) + (rg/√2 − δ) | 1.392 |
| 楔底半宽 | D_h/2 | 2.5 |
| 阵列节距 | 2π·R_track/N（须 > dBall） | 7.85 |

**自洽校验**：R_track − δ > rg（窝不穿透内盘）；**孔兼容性 R_h ≥ R_track + δ + t_wall（球放不进这个孔就报错）**；
zBall ∈ (rg, D_h−rg)（窝不出上下端面）；2π·R_track > N·dBall（球不叠）。

## 二、固定流程（实验室时间线 → 广义化 11 步）

1. **截面配方草图**（过孔轴平面）：三闭环（内盘/中环/外环轮廓，含窝弧+切线引出）+ **r=0 真线兼旋转轴**
2. **定向构造平面**（装球口切平面）：法向=装球口方位 e_r0，过切点（r=R_track+0.5，即中环外表面）
3. **装球口楔草图**：整三角轮廓（顶点球心等高，底在孔口端面）——轮廓必须真画在此平面上
4. **旋转 360°**（NewBody）→ 一次出三体（torus 球道 + 45° 引出锥自动成形）
5. **rg 球刀 CUT 中环** → 球面座
6. **凸雕 −1mm** → V 形装球口（打穿中环壁）
7. **倒角 r1**：只选装球口**外口的两条边**（凹陷与中环外圆柱的交界，1~2 条），半径 1mm
8. **⌀3 标准球** 放入球座
9. **圆周阵列 ×8**：选中环上窝+口+圆角那组面 + 球体，绕旋转轴整圈阵列（`CircularPatternFeature`，
   quantity=8 挂 ModelParameter 可参数化；实测中环 9→51 面、球 ×8）

（Demo 另含：宿主+掏孔 = 自造输入；反读孔 = 工具真实入口的验证。）

## 三、输入契约与基准系（广义化核心）

- 输入：一个**圆柱孔**（面），任意位置/姿态，深 5，不绑定世界 Z 轴
- **D_h=4 小球配方（⌀2.5/⌀2.381）的输入契约（2026-08-18 用户澄清）：孔深=零件厚度，
  即 4mm 板上的 ⌀16 通孔**——轴承总厚=板厚，整体 4mm（摆线盘偏心孔即此形态）；
  盲孔版也能建，但宿主底会多出无功能材料。反读不受影响：深度=两环缘沿轴投影差，通孔盲孔通吃
- 反读（全部从几何，零坐标假设）：
  - 圆柱面 → axis / radius
  - 孔底 = 法向∥轴、面积≈πR² 的平面圆盘 → Circle3D 边心 = **A0**（孔底圆心）
  - 环缘边（圆或椭圆）中心 → 定向 **u**（底→口），不依赖法线符号
  - 深度 = |环缘中心 − A0|（⚠️ 面积/2πR 反推法在斜孔下不准）
- 装球口方位 e_r0 任选 ⊥u；e_t = u×e_r0
- 坐标映射：`W_sec(r,y) = A0 + r·e_r0 − y·u`（y=0 孔底）；`W_wedge(x,y) = A0 + R3·e_r0 + y·u − x·e_t`
- 孔口若打在平顶面上是椭圆（轴≠面法向时孔壁浅侧极薄、轴承戳出顶面，**宿主很诡异**的根源）；
  真实契约应是**轴⊥孔口所在面**（孔口正圆），Demo 已改为斜圆柱墩宿主

## 四、落笔技巧（可复用）

- 草图可挂**任意平面**，曲线用「世界坐标 → 草图局部」逆映射落点：
  `sk.transform` 列向量约定（p_model = R·p_local + t，R 的**列**=轴；asArray 是行主序）
- **旋转特征吃 3D 落笔**（曲线世界位置正确即可）；**凸雕不吃**（校验"轮廓平行草图平面"）→ 凸雕草图必须建在真正定向的构造平面上
- 实体引用（构造平面 setter、草图点）不吃裸 Point3D，要 SketchPoint/顶点/边

## 六点四、命名与分组规范（脚本 ⑩.5/⑩.6 步自动执行）

- 组件按孔签名：`轴承-全-⌀XX`（多孔并存；融合特征 `轴承-宿主融合-⌀XX` 挂 root）
- 实体：`内盘` / `中环` / `球01…球NN`（自然序重命名，弃用 Fusion "(1)" 后缀；外环并入宿主）
- **选择集（⑩.6，2026-08-18）**：`球-⌀XX`（只含球，一键选中→隐藏/导出）+ `轴承-全部-⌀XX`
  （内盘+中环+全部球）。喂 **`occ.bRepBodies`（occurrence 视图=root 上下文实体）**，
  组件裸 body 会被拒；孔面输入集在融合后引用必死（0 实体），⑩.6 顺手清掉
- 脚手架（参考点/闭环/刀/楔草图、构造平面）全部隐藏，浏览器树只留成品
- ⚠ 用户手动合并/撤销会破坏该状态（选择集引用失效、组件消失）→ 重跑前先快照检查
- ⚠ `SelectionSets.add` 参数顺序是 **add(entities, name) —— 实体列表在前、名字在后**（3.14 实测 2026-08-18：
  名字在前必拒、ObjectCollection 也拒，只有 Python list + 名字在后能用；当初"重载坑"的真因就是顺序写反）

## 六点五、Fusion 侧完整脚本 v2（2026-08-18 审计修复后 PASS）

- **`scripts/gen_bearing_full.py`**：在选中孔上跑通完整 9 步 + **交付强制几何验收**
  （所有实体顶点必须落在孔系内、球心径向=R_track、内/外环含 Torus 真弧、凸雕凹凸判定，
  总结论 PASS 才算成功）。
- v1 审计发现的四项缺陷与修复：
  1. **位置错误**：v1 用"平面局部 2D 坐标"假设平面锚点在孔底心，实际 Fusion 自选参数化
     → 整个轴承建到世界原点。v2 全部改回「世界→草图局部逆映射」落笔（demo 验证过的路线）。
  2. **窝是折线**：v1 用 16 段折线绕 profile 问题（真因是闭环竖缘重叠自交，后来找到）；
     v2 恢复 `addByThreePoints` 真圆弧 → 内/外环出现 Torus 面（验收项）。
  3. **圆角选边三连错后找准**：外口侧棱(3.9mm²)→内壁(3.4)→球窝口沿整圈(14.0)都不对；
     最终答案=**凹陷面∩球窝面交界**（每球位 2 条、面片 1.192×2 = 实验室 1.188 ✓）。
     阵列特征复制不了 fillet（FILLET_NO_EDGE_FOUND）→ 改「先阵列、后圆角」16 边一次全倒。
  4. **凸雕 ±1 兜底有凸起风险**：v2 删兜底，改为读 nurbs 面质心径向位置判凹凸（r<R3=凹陷✓）。
- 3.14 API 坑（沿用）：revolve/combine/pattern 全是 3 参 createInput + operation/quantity/totalAngle 属性；
  combine 特征不可阵列（球刀体先阵列×N 再一次性 Cut）；凸雕/圆角/球特征可阵列；
  过轴平面 `setByThreePoints(3×草图点实体)`；输入=设计选择集（/exec 清 UI 选中）。
- **宿主融合与输入契约的自愈**：融合会吃掉孔壁面（选择集引用失效，孔面成为内部接缝消失）。
  脚本自愈：选择集空时从旧组件内盘圆柱面反推孔签名（轴+R_h=R1+2δ+t_wall）→ 删融合特征还原孔壁
  → 按签名找回 → 补回选择集「孔面」。重跑循环稳定（实测连续两轮自愈+全流程 PASS）。
- **排雷记录（2026-08-18 第二轮）**：①凸雕切点原取球心等高处（恰在球窝洞口内、不在 od_face 上，
  靠 Fusion 容错才没炸）→ 改 z=0.5（α0 方位外壁连续区）+ 平面法向验收（|n·er0|>0.99）+ 凹陷方位验收
  （联合包围盒质心，单片质心天然偏心不能用）；②补输入校验（孔深必须 5±0.2、孔径下限防窝穿内盘、
  斜孔正圆检查拒绝面积法回退）；③闭环/楔草图 profiles≠1 立即报错；④自愈失败记录原因不静默。
- **验收纪律**：特征创建成功 ≠ 几何正确。任何"生成成功"必须附几何证据
  （世界位置/面型/凹凸方向），bbox 对角会虚报径向（圆柱盒角=√2·R），用实体顶点采样。
